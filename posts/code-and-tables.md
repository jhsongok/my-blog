좁은 화면에서 가장 먼저 깨지는 것은 코드 블록과 표입니다.
이 블로그에서는 **페이지 전체가 아니라 해당 요소 안에서만** 가로로 스크롤되도록 했습니다.

## 코드 블록

```javascript
// 해시 주소를 읽어 어떤 화면을 보여줄지 정합니다.
function parseRoute() {
  const [name, ...rest] = location.hash.slice(2).split('/');
  return { name: name || 'home', param: decodeURIComponent(rest.join('/')) };
}
```

아주 긴 줄도 화면 밖으로 넘치지 않습니다.

```css
.prose pre { overflow-x: auto; } /* 이 한 줄이 핵심입니다. 아주 긴 주석을 붙여서 가로 스크롤이 생기는지 확인해 봅니다. */
```

언어를 적지 않은 코드 블록:

```
$ python -m http.server 8000
Serving HTTP on :: port 8000 (http://[::]:8000/) ...
```

## 표

| 기능 | 구현 방법 | 상태 |
|:-----|:----------|:----:|
| 다크 모드 | CSS 변수 + `data-theme` | ✅ |
| 라우팅 | `hashchange` 이벤트 | ✅ |
| 마크다운 | 직접 만든 파서 | ✅ |

열이 많은 넓은 표:

| 화면 너비 | 좌우 여백 | 본문 글자 크기 | 줄 간격 | 제목 크기 | 카드 여백 | 비고 |
|----------:|----------:|---------------:|--------:|----------:|----------:|------|
| 360px | 16px | 17px | 1.75 | 1.85rem | 20px | 휴대폰 |
| 768px | 24px | 17px | 1.75 | 2.25rem | 24px | 태블릿 |
| 1280px | 24px | 17px | 1.75 | 2.25rem | 24px | 데스크톱 (본문 최대 720px) |
