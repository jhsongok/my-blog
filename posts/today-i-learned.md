오늘은 클로드 코드와 함께 이 블로그를 처음부터 만들었습니다.
프레임워크 없이 HTML, CSS, JavaScript만 쓰다 보니 세 가지가 각각 무슨 일을 하는지 또렷하게 보였습니다.

한 문장으로 줄이면 이렇습니다.

> **HTML은 뼈대, CSS는 옷, JavaScript는 움직임.**

## HTML: 구조와 의미

HTML은 페이지에 **무엇이 있는지**를 정합니다. 제목, 본문, 머리말, 꼬리말 같은 덩어리를 태그로 나눕니다.

```html
<header>블로그 이름과 테마 버튼</header>
<main id="app">글 목록이나 본문이 들어갈 자리</main>
<footer>저작권 표시</footer>
```

- `<div>`만 쓰지 않고 `<header>`, `<main>`, `<article>`처럼 **뜻이 있는 태그**를 쓰면 화면 낭독기나 검색 엔진도 구조를 이해합니다.
- `<meta name="viewport">` 한 줄이 없으면 휴대폰에서 화면이 작게 축소되어 보입니다.

## CSS: 모양과 배치

CSS는 HTML이 **어떻게 보일지**를 정합니다. 색, 글꼴, 여백, 배치가 모두 CSS의 일입니다.

```css
:root { --accent: #2f6fdb; }
.post-title { color: var(--accent); }
```

- 색을 **CSS 변수**로 모아 두니, 다크 모드는 변수 값만 바꾸면 끝났습니다. 글 제목을 파란색으로 바꿀 때도 한 줄이면 충분했습니다.
- `@media`로 화면 너비에 따라 여백과 글자 크기를 바꾸면 휴대폰에서도 읽기 편해집니다.
- 긴 코드 블록은 `overflow-x: auto`를 주면 페이지 전체가 아니라 그 칸 안에서만 가로로 스크롤됩니다.

## JavaScript: 동작과 데이터

JavaScript는 페이지가 **무엇을 할지**를 정합니다. 이 블로그에서는 세 가지 일을 맡았습니다.

1. 주소의 `#/post/...` 부분을 읽어 어떤 화면을 보여줄지 정합니다.
2. `fetch()`로 마크다운 파일을 불러와 HTML로 바꿔 화면에 넣습니다.
3. 테마 버튼을 누르면 다크 모드로 바꾸고, 그 선택을 브라우저에 저장합니다.

이때 알게 된 점이 두 가지 있습니다.

- 파일을 더블클릭해서 열면 `fetch()`가 막힙니다. 그래서 `python -m http.server` 같은 로컬 서버가 필요합니다.
- 글 내용을 그대로 `innerHTML`에 넣으면 그 안의 스크립트가 실행될 수 있습니다. 그래서 `<`, `>` 같은 문자를 먼저 바꿔 주는 **이스케이프** 처리가 꼭 필요합니다.

## 세 가지를 나눠 두면 좋은 점

| 역할 | 담당 | 파일 |
|:-----|:-----|:-----|
| 무엇이 있는가 | HTML | `index.html` |
| 어떻게 보이는가 | CSS | `css/style.css` |
| 무엇을 하는가 | JavaScript | `js/*.js` |

디자인을 고칠 때는 CSS만, 기능을 고칠 때는 JavaScript만 보면 됩니다.
역할을 나눠 두는 것만으로 코드를 고치기가 훨씬 쉬워진다는 것이 오늘 배운 가장 큰 교훈입니다.
